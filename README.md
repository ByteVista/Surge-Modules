# Romeo Surge 模块安装目录

按 [Romeo / Modules/Surge](https://github.com/ifflagged/Romeo/tree/main/Modules/Surge) 的一级目录标注作者。这里仅整理说明与安装链接，模块和运行脚本由 Surge 直接从 Romeo 获取。

共 **36 个作者目录、3,129 项模块、7,911 个版本文件**，按“首页 → 作者 → 模块列表”浏览；条目较多的作者再按软件名称分页，每页最多 100 项。默认目录、Beta、Official 中的同名文件合并为一行，不合并不同作者或不同文件名的模块；根目录文件单独标注。

## 使用方法

先在下方选择作者，再点击模块表内“安装”，通过 HTTPS 中转页打开 Surge；首次访问 raw.githack.com 可能需确认访问。安装页提供当前模块存在的默认目录 / Beta / Official 版本及直接订阅地址，可按需切换。默认选择具有较完整配置内容的版本，不代表经过设备端效果测试。

GitHub 会过滤 README 中的 `surge://` 链接，因此使用一个小型安装跳转页；不使用 Pages，不需要 GitHub Pro。若没有打开 Surge，点击安装页的“打开 Surge 安装”，或复制订阅地址到 Surge 的“从 URL 安装”。

作者列依据目录名填写；原文中的合作作者、使用要求、完整说明及版权声明，以安装页提供的模块原文为准。用途列摘取上游描述的前 20 个字；原文没有描述时明确标记。请按需选择，同一软件不要同时启用多位作者的同类模块。

整理时间：2026-11-10；目录快照：[Romeo `943c336`](https://github.com/ifflagged/Romeo/tree/943c3360afa9914acb9daaf1adb4735b40d31c6d/Modules/Surge)。安装地址跟随上游 `main`，上游后续新增或删除的文件需要重新整理目录。
